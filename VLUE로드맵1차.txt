채팅창에 전송되는 내 명함이 단순 이미지로 복제되는 걸 막기 위해 채팅창 업로드 명함도 '보안 애니메이션'을 강화해줘.

CSS 애니메이션을 채팅방 명함전송에도 적용시켜줘
렌더링 방식: 명함을 이미지 파일(.jpg, .png)로 전송했을때 다운로드 되면 안돼! HTML/CSS로 그려진 **'라이브 컴포넌트'**로 렌더링해줘. 그래야 내부의 애니메이션이 계속 작동하니까.
그리고 지금 전체 명함/인터페이스 전면 수정하자. 해당 명함에 전화번호가 빠졌다. 각 해당 전화번호를 넣어줘.(스텐다드/프리미엄)그리고 프리미엄 명함은 명함을 탭하면 뒷면을 제공한다.
어떤일을 하는지 자기고 홍보하고 싶은 내용을 넣을수 있는 뒷면을 제공한다. 이부분은 프리미엄만 적용한다. 인증명함이 있는 부분은 일괄 수정해야해!
"복제가 불가능한 '살아있는 디지털 명함' 느낌이 나도록 [Apply] 해줘!

명함의 보안을 지키면서 사용자가 명함을 편리하게 관리할 수 있도록 '명함 지갑(Wallet)' 로직을 추가해줘.

1. [명함첩 저장] 버튼: 채팅방에 올라온 명함 하단에 2개의 버튼을 생성해'명함 저장하기''명함 전달하기' 버튼을 만들어. 클릭 시 해당 유저의 ID와 정보를 서버(Supabase)의 card_wallet 테이블에 저장해. 
2. 명함지갑(WALLET) 페이지:  기존 입력창 좌측에 (+)이 버튼안에 넣어. 지금 자리가 없어서 수정을 조금하자. (내명함/내상점) 이걸 내프로필 로 명칭으로 바꾸고 그버튼안에 2개를 만들어줘 탭하면 팝이 뜨면서 (내명함 보내기/내 상점 보내기)로 만들어줘 그리고 원래 내 상점 있던자리를 명함지갑이라고 만들어줘. 
3. 라이브 데이터 연결: 명함첩에 저장된 정보는 원본 유저의 프로필 데이터와 동기화되어, 원본이 수정되면 명함첩 내 정보도 즉시 바뀌도록 설계해.
4. 시각적 경험: 명함첩에서 명함을 클릭하면 아까 만든 '보안 애니메이션(홀로그램)'이 부드럽게 재생되면서 상세 정보가 펼쳐지게 해줘.

3. UI/UX 구성:

메인 화면의 [구독 업데이트] 섹션 상단에 인스타그램 스토리처럼 동그란 프로필 아이콘을 배치하고, 이를 누르면 릴스 형태의 영상 피드가 바로 시작되게 해줘.

4. 서버비 최적화: 외부 스토리지 최적화

Supabase Storage 또는 AWS S3를 사용하되, **CDN(CloudFront 등)**을 반드시 연결하여 동일 영상에 대한 중복 트래픽 비용을 최소화할 것.

모든 영상의 해상도는 720을 넘지않게 해줘.

모든 영상 데이터는 외부 스토리지(예: AWS S3 + CloudFront)를 통해 스트리밍 방식으로 처리하고, 사용자가 현재 보고 있는 영상만 데이터를 소모하도록 지연 로딩을 철저히 적용해줘."
