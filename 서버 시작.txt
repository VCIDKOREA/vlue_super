출시 준비 순서를 정확히 안내하기 위해 프로젝트의 배포·환경 설정 구성을 확인합니다.

코드·deployment.lock.json·.env.production 매니페스트 기준으로, 실서버 가동 → API 연동 → 출시 순서를 단계별로 정리했습니다. 위에서부터 진행하면 되고, 각 단계에서 준비할 키/계정만 미리 챙기시면 됩니다.
전체 구조 (한 줄 요약)
도메인·서버 → DB/Redis → DB 마이그레이션 → API 실 ENV → 외부 API 키 → 프론트 빌드·배포 → 웹훅·크론 → 스모크 테스트 → 오픈

용도예시웹(프론트)
https://www.vlue.kr
API
https://api.vlue.kr

목표: API·웹·DB·Redis가 붙을 자리 확보

PostgreSQL 16 (관리형 Supabase/RDS 또는 자가 호스팅)
Redis (관리형 ElastiCache/Upstash 또는 자가 호스팅)
