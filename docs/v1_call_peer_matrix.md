# V1 통화 제어 · 통화 목록 규제 매트릭스

공유 판별: `web/src/lib/call/callPeerMatrix.js` (회원 / **기기** 주소록 / 쇼케이스 보관함)

## 통화 중 (In-Call) · 풀케이스 미리보기

하단: **키패드 · 음소거 · 스피커** (+ 실통화 시 종료)

| 조건 | CTA |
|------|-----|
| 미회원 + 기기 주소록 (실통화만) | 카톡으로 쇼케이스 전달하기 |
| 그 외 | CTA 없음 |

**저장 버튼은 통화 목록 다시보기에만** (`fromCallHistory`) 노출.

## 통화 목록

| 회원 | 주소록 | 보관함 | 버튼 |
|------|--------|--------|------|

| Y | * | Y | 없음 |

| N | N | * | 없음 |
