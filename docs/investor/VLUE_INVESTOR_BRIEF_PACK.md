## 2. 미션 · 비전 · 추구 방향

**미션**  
사기 전화·문자를 **받기 전에** 확인하고, 피해를 예방한다.

**비전**  
검증된 데이터 위에 쌓인 **국내 대표 디지털 신뢰·통화 보호 플랫폼**.

**세 기둥**

1. **신뢰 검증** — 공공 DB + VLUÉ 인증 DB 이중 조회로 기관·번호 신뢰도를 제시  
2. **실시간 보호** — 설치형 앱에서 통화 쇼케이스·인증명함·가족 이상 징후 안내  
3. **개인케이스** — 웹·앱 동일 계정으로 명함·저장케이스·문서 관리

**제품 철학 (핵심 포지셔닝)**  
일반 전화(PSTN) 회선은 통신사·기본 전화앱이 담당하고, VLUÉ는 **통화 이벤트를 이해해 맥락형 신뢰 UI(오버레이·쇼케이스·안심 팝업)** 를 제공하는 **Companion Platform**이다. “전화앱을 대체한다”가 아니라 **신뢰 레이어를 올린다**.

**슬로건 방향 (카피)**  
「모르는 번호에 속지 마라, 아는 번호라도 확인하라」

## 3. 문제 · 시장 내러티브 (사업계획서용)

**사용자 고통 (제품이 실제로 다루는 문제)**

1. 모르는·의심 번호의 신원·소속을 즉시 알기 어렵다  
2. 아는 번호도 사칭·오인 위험이 있다 → 통화 중 **인증·프로필**이 필요  
3. 사업자·개인이 전화로 명함·포트폴리오·연락처를 한 화면에 보여 주기 어렵다  
4. 가족 구성원의 위험 통화·링크를 보호자가 알기 어렵다  

**시장 내러티브(서비스소개 페이지 기준 · 사업계획서에 쓸 때 출처·최신 통계로 재검증 권장)**

| 지표(사이트 카피) | 값 |
|-------------------|-----|
| 2023년 피싱 피해액 | 7,500억+ |
| 연간 피해 신고 | 약 18만 건 |
| 사전 예방 가능(카피) | 정보 확인만으로도 상당 부분 차단 가능 |

> 투자 문서에는 “자사 마케팅 카피”와 “공신력 있는 외부 통계”를 구분 표기할 것.

## 4. 제품 한 줄 정의

VLUÉ는 **일반 전화(PSTN) 통화 중**에 상대/본인에게 **블루 쇼케이스·디지털 인증명함**을 보여주고, **PASS 본인인증·기관/번호 검색**으로 신원을 확인하게 하는 **모바일 앱 + 검색·안내용 웹**이다.

| 채널 | 역할 |
|------|------|
| 웹 www | 기관·전화·사업자 검색, 요금·다운로드·고객지원·가족보호·개인케이스 안내 |
| 앱(Android 중심 · iOS 셸) | 통화 오버레이·쇼케이스 송출·가입·구독 결제·InCall |

## 5. 핵심 기능 (사업계획 ‘제품’ + 설명서 ‘목차’)

### 5-1. 반드시 강조할 V1 축

| 축 | 사용자 가치 | 상태(제품 문서) |
|----|-------------|-----------------|
| PASS 본인인증 | 번호·계정 신뢰 바인딩 | 완료 |
| 기관·전화·사업자 검색 | 받기 전 검증 | 완료 |
| 통화 오버레이(빅푸시·쇼케이스·안심/인증 팝업·미니) | 통화 중 신뢰 UI | 아키텍처 완료 · 실기기 지속 검증 |
| 디지털 인증명함 | 유료·B2B 신뢰 명함 | 완료 |
| 블루 쇼케이스(최대 5p+명함) | 소개·브랜드 송출 | 완료 |
| InCall 제어(키패드·음소거·스피커·종료) | 전화앱과 공존 | UI 완료 · Dialer 실기기 검증 지속 |
| 가족보호 | 유료 보호자–피보호자 | 부분 구현 |
| 카톡 Share 초대 | 미설치 상대에게 쇼케이스 전달 | 완료 |

### 5-2. 통화 UX (설명서·데모 스크립트용 · 고정 규격)

- **수신:** 빅푸시(상단) → 응답 후 안심/인증 팝업 또는 풀 쇼케이스 → 확인 시 미니  
- **발신:** 중앙 VLUÉ 로고 → 응답 후에도 로고 유지 → **사용자가 로고 탭** 후 팝업/쇼케이스 → 확인 시 미니  
- **수신에 발신 로고 금지** (규격 고정, v1.0.15 검증 PASS)

상세: `CALL_OVERLAY_CONTRACT.md` (대외 설명서는 사용자 언어로만 요약, 내부 규격명은 생략 가능)

### 5-3. 의도적 V2 / 비노출 (과대 약속 방지)

스토어·쇼핑, 이메일/메일톡, 추천인(VLUER), 웹 구독 결제 등은 **V2 또는 플래그 비활성** — 사업계획서에서 “출시 예정”으로만 다루고 V1 매출 전제로 넣지 말 것.

## 6. 비즈니스 모델 (공개 요금 골격)

근거: `membershipBm.js` / 서비스소개 요금표 · **이벤트 요금은 변동 가능** → 문서에 “V1 이벤트 가격” 명시.

| 티어 | 골격 | 핵심 혜택 |
|------|------|-----------|
| 무료 | 0원 | 통화·신원 확인, 기본 쇼케이스 |
| 유료(Premium) | 월 **9,900** / 연 **99,000** (정가 월 28,300 이벤트) | 풀 쇼케이스·디지털 인증명함·가족보호(1:3) 등 |
| B2B | 대표 정가 골격 + 직원 회선 이벤트(예: 직원 **5,200**/월) | 회선·CI·대표번호 체계 |
| SOHO 추가번호 송출 | **+4,200**/월 | 옵션 SKU |

수익 논리(투자자용 한 줄):  
**신뢰 검색(웹 유입) → 앱 설치 → PASS → 유료 명함·쇼케이스·가족보호 / 기업 회선 구독.**

결제: 앱 경로 PortOne 빌링 · www는 V1에서 구독 결제 비활성(앱 다운로드 유도).

## 7. 기술·차별점 (과도한 내부 디테일 제외)

| 포인트 | 투자자용 표현 |
|--------|----------------|
| Companion | 통신사 회선 유지 + 앱이 신뢰 UI 제공 |
| 이벤트 드리븐 오버레이 | 벨·응답·종료 등 실제 통화 이벤트에 맞춘 UI |
| 본인인증 일관성 | PASS로 묶인 번호 = 쇼케이스·검색·명함에 쓰는 신원 |
| 이중 DB | 공공 디렉터리 + VLUÉ 인증 상태 |
| 스택(요약) | Web(React) · API(Hono) · PostgreSQL · Android/iOS 네이티브 셸 + WebView · R2 미디어 |

상세 아키텍처 문서는 **기술 DD 요청 시 NDA 후** 제공 권장.
