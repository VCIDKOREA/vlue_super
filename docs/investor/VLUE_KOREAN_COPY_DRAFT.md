## 1. 표지·한 줄 소개

**VLUÉ — 믿을 수 있는 연결, 안전한 일상**

VLUÉ(블루)는 보이스피싱·기관 사칭 피해를 줄이고, 검증된 기관과 사람이 안심하고 소통할 수 있도록 돕는 **디지털 신뢰·통화 보호 플랫폼**입니다.  
일반 전화(PSTN) 회선은 그대로 두고, 통화 순간에 **신뢰 정보·디지털 명함·쇼케이스**를 보여 주는 **Companion(동반) 레이어**를 제공합니다.

Powered by **VCID KOREA** · 문의 support@vlue.kr

---

## 2. Executive Summary (사업계획서 서두)

국내 보이스피싱 피해는 매년 수천억 원 규모로 확대되고 있으며, 사용자는 “모르는 번호”뿐 아니라 “아는 번호를 사칭한 전화”까지 경계해야 합니다.  
VLUÉ는 **공공·자체 인증 데이터**와 **PASS 본인인증**을 결합해, 전화를 받거나 거는 **그 순간**에 상대 신원·경로를 확인할 수 있는 환경을 만듭니다.

웹(www.vlue.kr)에서는 기관·전화번호·사업자번호 **통합 검색**을 제공하고, 모바일 앱에서는 **통화 오버레이·블루 쇼케이스·디지털 인증명함·가족보호**를 하나의 계정으로 연결합니다.  
VLUÉ는 통신사 회선이나 기본 전화앱을 대체하지 않으며, **신뢰 UI만을 올리는 Companion Platform**으로 포지셔닝합니다.

---

## 3. 문제 정의

1. **모르는 번호** — 상대가 누구인지, 어떤 기관·업체인지 즉시 알기 어렵다.  
2. **아는 번호의 사칭** — 저장된 이름·번호라도 보이스피싱·원격제어 유도에 취약하다.  
3. **전화로 자기소개의 한계** — 명함·포트폴리오·공식 연락처를 한 화면에 보여 주기 어렵다.  
4. **가족 보호** — 보호자가 가족의 위험 통화·의심 연락을 알기 어렵다.

**제품 슬로건 방향**  
「모르는 번호에 속지 마라, 아는 번호라도 확인하라」

### 4-2. 핵심 기능 (V1)

- **PASS 본인인증** — 계정·전화번호 신원 바인딩  
- **통합 검색** — 기관명·전화·사업자번호 대조 (공공 + VLUÉ 인증 DB)  
- **통화 오버레이** — 수신 빅푸시 → 수화 후 안심/인증 팝업 또는 쇼케이스 → 미니  
- **발신 UX** — 중앙 VLUÉ 로고 → 수화 후 사용자 탭 시 팝업/쇼케이스 → 미니  
- **디지털 인증명함·블루 쇼케이스** — 유료·B2B 중심 송출  
- **가족보호** — 유료 계정의 등록 가족 알림·설정 (E2E 검증 지속)  
- **카카오 Share** — 미설치 상대에게 쇼케이스 초대  

### 4-3. 기술·차별 (투자자용 요약)

- PSTN 유지 + **이벤트 기반 Companion 오버레이**

- **이중 DB**(공공 디렉터리 + VLUÉ 인증)  
- Web(React) · API(Hono) · PostgreSQL · Android/iOS 네이티브 셸 + WebView · R2 미디어

# 앱 사용설명서 — 본문 초안

## A. VLUÉ란?

VLUÉ는 **전화를 더 안전하고 투명하게** 쓰기 위한 앱입니다.  
통화 중 상대방의 **신뢰 정보·쇼케이스·디지털 명함**을 화면에 보여 주고, **기관·번호 검색**으로 받기 전에 확인할 수 있습니다.

---

## B. 시작하기

1. **앱 설치** — Google Play(또는 배포 채널)에서 VLUÉ 설치  
2. **권한** — 통화 표시(오버레이), 연락처(저장 번호 안심 표시), 필요 시 **기본 전화앱** 역할(Android)  
3. **가입** — 휴대폰 번호 로그인  
4. **PASS 본인인증** — 실명·번호 확인 (필수)  
5. **유료 선택** — 디지털 인증명함·풀 쇼케이스·가족보호 이용 시 구독  

웹(www.vlue.kr)에서도 **검색·요금·고객지원**을 이용할 수 있으며, **V1 구독 결제는 앱**에서 진행합니다.

---

## C. 홈 · 검색

- **홈 검색창:** 기관명·전화번호·사업자번호 입력 → 공공·VLUÉ 데이터 조회  
- **개인케이스:** 명함 저장·저장된 케이스·내문서 (웹·앱 동일 계정)

---

## D. 쇼케이스 · 디지털 인증명함 (유료·B2B)

1. 홈 또는 설정에서 **스타일·사진·링크·BGM** 편집  
2. **통화화면 보기**로 본인 통화 UI 미리보기  
3. **송출 ON/OFF**에 따라 상대에게 보이는 범위가 달라집니다  

무료 회원은 기본 쇼케이스, 유료·B2B는 **디지털 인증명함 + 풀 쇼케이스**를 이용합니다.

---

## E. 수신 전화 (빅푸시 → 팝업/쇼케이스 → 미니)

1. 전화가 오면 화면 **상단 빅푸시**에 상대 정보가 표시됩니다.  
2. **기기에 저장된 번호**는 가능한 한 빨리 **이름(안심케어)** 로 표시됩니다.  
3. **전화를 받으면(수화)**  
   - VLUÉ 비회원·주소록 연락처 → **안심 정상 팝업** (경로 검증)  
   - VLUÉ 인증 회원(송출 OFF) → **인증 팝업**  
   - 송출 ON + 콘텐츠 있음 → **풀 쇼케이스**  
4. 팝업에서 **확인** → **미니 케이스**로 전환 (통화 중 다른 앱 사용 가능)  
5. 미니를 탭하면 다시 쇼케이스·팝업으로 복원할 수 있습니다  

---

## F. 발신 전화 (중앙 로고 → 탭 → 팝업/쇼케이스 → 미니)

1. 전화를 걸면 **중앙 VLUÉ 로고**가 표시됩니다 (상대 이름 빅푸시와 분리).  
2. **상대가 받을 때까지** 자동으로 큰 팝업·쇼케이스는 열리지 않습니다.  
3. **연결된 뒤**, 중앙 로고를 **탭**하면 수신과 동일한 규칙으로 팝업·쇼케이스가 열립니다.  
4. **확인** → **미니 케이스**
