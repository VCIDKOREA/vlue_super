> **문서 등급:** **CONFIDENTIAL — 사내 한정**  
> **열람:** 대표 · 지정 임원 · 보안 담당 · (필요 시) 법무만  
> **금지:** 투자자 IR 패키지, 외부 메일, 공유 드라이브 공개 폴더, 채팅 첨부, GitHub Public 이슈/위키 무단 게시

## 1. 목적

투자의향·사업계획·앱설명서 제작 시 **대외 공개 가능 정보**와 **사내 보안 정보**를 분리한다.  
본 문서는 “무엇을 보안파일로 잡고 투자자에게 주지 않는가”의 **회사 내 규정**이다.

## 7. 투자 자료 제작 시 체크 (필수)

1. IR PDF/ZIP 만들기 전 **본 문서 §3–4 파일 경로가 포함되지 않았는지** 검색  
2. 스크린샷에 **실명·실번호·관리자 화면·환경변수**가 없는지 확인  
3. 데모 계정은 P1과 분리된 **데모 전용**만 기재  
4. “기술 차별점”은 Companion·PASS·이중 DB·BM 수준으로 止め, 키·엔드포인트 시크릿·우회법 금지  
5. 재무·지분은 별도 `[P1]` 패키지 · 본 브리프와 파일명부터 분리
