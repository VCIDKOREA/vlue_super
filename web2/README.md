# VLUE - 보이스피싱 방지 플랫폼

디지털 명함을 통한 기관 인증 및 보이스피싱 방지 서비스

## 주요 기능
- 실시간 보이스피싱 경보
- VLUE 기관 인증 조회
- 위치기반 안심영역 설정
- 피해 즉시 신고 기능

## 기술 스택
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Supabase
- Lucide React Icons

## 설치 및 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```
